# NEMAS
Implementation of NEMAS: Norm Entrepreneurship in Multi-Agent Systems

This repository contains the Python implementation of NEMAS (Norm Entrepreneurship in Multi-Agent Systems) developed as part of my PhD research.

NEMAS investigates how peer agents can identify local coordination problems, construct local coordination solutions, abstract these solutions into reusable candidate coordination norms, and reuse and propagate these across an agent society.

Repository Contents

The implementation includes components for:

multi-agent grid-world simulation;
identification of local regions of coordination (ROCs);
calculation and quantisation of agent regret landscapes;
construction of contour-tree representations;
structural comparison of coordination scenarios;
generation of local coordination solutions;
construction of coordination state machines;
abstraction of coordination solutions into reusable candidate coordiantion norms;
selection and execution of coordination solutions; and
candidate coordiantion reuse and propagation.
